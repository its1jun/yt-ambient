# 적용 가이드
1. 파일 다운
  - `<> Code` ➔ `Download ZIP`
2. 압축해제
3. 아래 링크 접속
  ```text
  chrome://extensions
  ```
4. 오른쪽 위 "개발자 모드" 켜기
5. 왼쪽 위 "압축해제된 확장 프로그램 로드" 실행  
  ***주의:** 폴더 속 하위 폴더 선택*
   ```text
   yt-ambient-release/
   └── yt-ambient-release/   ⬅ 이거 선택
       ├── assets/
       ├── config/
       ├── dist/
       ├── popup/
       ├── styles/
       └── manifest.json
   ```
